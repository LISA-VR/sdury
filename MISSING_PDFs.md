# Papers without a downloaded PDF

Downloaded PDFs live in `assets/pdf/` (not committed to git).
This list is the set of publications on the site for which no openly
accessible PDF could be found on 2026-09-28.

## Why some are missing

- **IEEE Xplore** papers (no OA version): the publisher pages block
  automated access and no author copy is publicly mirrored.
- **SPIE** proceedings: paywalled, no open copy.
- **Invited talks / workshop notes / MPEG documents**: not published
  with a DOI, no public PDF.
- **PhD thesis**: available through ULB Di-Fusion but the repository's
  search and full-text interfaces were unreachable from this network at
  build time.
